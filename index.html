Chords
[C]Inline chord — placed directly before the syllable it falls on
[Am] [F#m7]Any chord name: major, minor, 7th, sus, add, dim, aug, etc.
[C/E]Slash chord — bass note after the slash
{define: C base-fret 1 frets x 3 2 0 1 0}Defines a fretboard diagram for chord C (6 values, low E string to high e string; x = muted, 0 = open, a number = fret position). Any [C] after this line shows a dotted underline — click it to view the diagram.
{define: C base-fret 8 frets x 3 5 5 5 3 fingers x 1 3 4 4 1}Optional fingers list (same order, 1–4) labels each dot and lets adjacent same-finger dots merge into a barre. base-fret 8 shows "8fr" beside the diagram instead of a nut.
Redefining a name{define:} only affects chords appearing after it. The same name (e.g. C) can have a different diagram earlier vs. later in the song — handy for showing a chord played in a different position partway through.

ABC Music Notation
{start_of_abc}Begin an ABC notation block — renders standard notation with guitar tab below
{end_of_abc}End the ABC notation block
{soabc} / {eoabc}Shorthands for start / end of ABC notation
{start_of_abc}
X:1
M:4/4
L:1/8
K:G
|"G"G4 G2AB|"C"c4 c2BA|"D"D6 DE|"G"G8|]
{end_of_abc}
ABC notation is a text-based music standard. Each block must begin with X:1 (tune number), M: (time signature), L: (note length), and K: (key).
Full syntax reference: abcwiki.org/abc:syntax  ·  abcnotation.com
VexTab Notation (Exact Fret Positions)
{start_of_vextab}Begin a VexTab block — renders standard notation + tab with exact fret/string positions
{end_of_vextab}End the VexTab block
{sovt} / {eovt}Shorthands for start / end of VexTab
{start_of_vextab}
options space=20
tabstave notation=true key=G time=4/4
notes :q 5/3 7/3 5/2 3/2 | :h 5/3 :q 4/3 5/3
{end_of_vextab}
Fret notation: fret/string — e.g. 5/3 = fret 5, string 3 (G). Strings: 1=high e, 2=B, 3=G, 4=D, 5=A, 6=low E.
Note lengths: :w whole, :h half, :q quarter, :8 eighth, :16 sixteenth.
Techniques: 5h7/3 hammer-on, 7p5/3 pull-off, 5s7/3 slide, 5b7/3 bend, t12/3 tap.
Chords: (5/3.5/2.5/1) — notes in parentheses play together.
Use tabstave notation=true for both notation + tab, or notation=false for tab only.
Full tutorial & syntax: vexflow.com/vextab/tutorial.html

⛶ Full screenExpands the preview to fill the screen with larger text — ideal for performances. Press Esc to exit.
◀ / ▶Step through songs in a loaded setlist — also works with Page Up/Down or Left/Right arrow keys
▶ Auto-scrollSmoothly scrolls the preview for hands-free reading — toggle with the button or the Spacebar (when not typing)
Auto-scroll − / +Adjust scroll speed in steps of 0.5 (range 0.5–10) — your chosen speed is remembered
Auto-scroll speed fieldClick and type to enter an exact speed (e.g. 3.1) — press Enter to apply
Manual scrollTouching, clicking, or using the mouse wheel on the preview automatically pauses auto-scroll

NewClears the editor to start a new song (prompts if unsaved changes)
SaveSaves the current file — prompts for a filename if new, then asks for tags

☆ FavsShow only starred songs — star any song by hovering and clicking ☆

↗ ShareShare a song or setlist — generates a link you can copy or send by email
